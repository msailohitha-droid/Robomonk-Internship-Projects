# RoboMonk Internship Projects

This repository showcases the mini-projects completed during my **Embedded Systems Internship at RoboMonk Technologies Private Limited**.

## Projects Included

1. Battery Voltage Indicator
2. Clap Control Switch
3. Door Open Alert System
4. Visitor Counter System
5. Sound Activated Light System
6. Touch Control Lamp
7. Smart Dustbin

## Repository Contents

This repository contains project photographs, documentation, and brief descriptions explaining the working principle of each project.

These projects provided practical exposure to sensors, electronic components, Arduino-based systems, and basic embedded systems applications.
