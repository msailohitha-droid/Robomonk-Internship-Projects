**Touch Control Lamp**

The Touch Control Lamp uses a touch sensor to control the ON/OFF operation of an LED through touch-based input.

- **Touch Detection:** The touch sensor detects when a user touches its surface.
- **LED Activation:** On the first touch, the LED turns ON and blinks.
- **LED Deactivation:** On the second touch, the LED turns OFF.

The system demonstrates simple touch-based control of lighting.
