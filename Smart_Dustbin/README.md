**Smart Dustbin**

The Smart Dustbin uses an IR sensor to detect the waste level inside the dustbin and provides an alert when it becomes full.

- **Waste Level Detection:** An IR sensor placed at the top of the dustbin detects when the waste reaches the specified level.
- **Status Indication:** The system detects when the dustbin is full and changes the LED status.
- **Alert System:** When the dustbin is full, the buzzer sounds to alert the user that it needs to be emptied.
