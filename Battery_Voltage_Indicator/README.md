# Battery Voltage Indicator

This mini project was completed as part of my **Embedded Systems Internship at RoboMonk Technologies Private Limited**.

The Battery Voltage Indicator monitors the battery voltage and indicates its charge level using three LEDs:

- **Green LED:** Indicates a high battery level.
- **Yellow LED:** Indicates a medium battery level.
- **Red LED:** Indicates a low battery level.

The system provides a simple visual indication of the battery's voltage condition, making it easy to identify the battery level.
